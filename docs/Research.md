# Research checkpoint

Initial public-web review: 2026-10-12. Marketing/documentation review, not hands-on trials. Prices and capabilities require fresh verification before spending or selection.

## Closest catalog leads

- Cutterly: https://cutterly.pro/ — cutter and finished-cookie photos, tags/search, locations, sets. Independent searchable design records/STLs/bulk export unverified.
- Sweet Bite: https://sweetbiteapp.com/ — browser-based cutter/supply inventory, locations, tags, additional photos on paid plan. Relationship/file/export behavior unverified.
- CutterVault: https://apps.apple.com/us/app/cuttervault/id6761496099 — photos/tags/locations/collections; updates mention import/export and multiple images. Independent design search unverified.
- Cutter Closet: https://apps.apple.com/us/app/cutter-closet/id6793692664 — advertised AI shape identification, inventory, bins, duplicate detection, project lists. Identification does not establish new flip discovery.
- Cookie Blueprint: https://apps.apple.com/us/app/cookie-blueprint/id6793680348 — inventory and project planning.
- Peeknest: https://www.peeknest.com/cookie-cutters — general visual inventory with cookie-cutter use case.
- BakerSuite: https://bakersuite.com/ — advertises cutter catalog within bakery management; public detail limited.

## Adjacent tools

- CookieSketch: https://apps.apple.com/us/app/cookiesketch/id6758695679 — decorating sketches and order sets.
- Procreate cookie resources: https://cakeandcookieplanner.com/pages/procreate-digital-cookie-sketching
- Cutter Canvas: https://cuttercanvas.com/creator — advertised STL creation, icing design, projector guides; existing collection import unverified.
- Cookiecad: https://cookiecad.com/ — artwork-to-printable tools.
- BakePress: https://www.bakepress.com/ — printable cutter creation and batch/size workflows.
- Manyfold: https://manyfold.app/ — 3D file library, previews, tags, sources, duplicates; not established as a cookie-design/physical-location system.
- Eagle: https://eagle.cool/ — visual asset organization and advertised visual/semantic search; geometric cutter compatibility unverified.
- Airtable: https://airtable.com/pricing — adaptable linked records; free record limits apply across a base, not just cutter records.

## Organization and reuse

- https://www.thefrostedkitchen.com/organizing-your-cookie-cutters/ — category bins and labels.
- https://sweetcookiejourney.com/cookie-cutters-organizer/ — physical/vendor images, name/size reference cards, box-by-box intake.
- https://www.wecookiers.com/cookie-cutter-flips.html — known flips, morphing, and frankencookie concepts.

## Conclusion and limits

Existing products plausibly solve cutter inventory and record known alternate uses with photos/tags. The review did not verify a complete unified solution for physical inventory, existing printable assets, independent searchable designs, explicit compatibility mappings, and automatic new flip suggestions. This is an evidence gap, not proof that no such product exists.

User selected durable project bootstrap and infrastructure planning for a custom catalog. Preserve these references as comparison inputs; do not treat vendor claims as tested capability.
