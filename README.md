# Cookie Catalog

**R1 v0.1.0 is released.** Browse, search and edit your collection at [Production Cookie Catalog](https://cookie-catalog-prod.j-brickey.workers.dev/).

[Development](https://cookie-catalog-dev.j-brickey.workers.dev/) is for testing. Use production for real catalog changes.

The app provides inline editing and record Undo, focused image cards and downloads, multi-term search/reset, context help, linked physical inventory and private managed backups. Images alone do not establish physical size or ownership.
